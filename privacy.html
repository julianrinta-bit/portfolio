Privacy Policy

Applies to the personal tool “Julian Rinta Tool App” · Last updated 13 November 2026

What this covers

“Julian Rinta Tool App” is a private command-line utility that Julian Rinta runs on his own computer to work with his own accounts. It is not a product, it is not offered to anyone else, and it has no users other than its owner.

What it accesses, and only when authorised

The tool can request access to the following Google services, and only for an account whose owner has explicitly granted it through Google’s own consent screen:

  • Gmail — reading, searching, composing and managing messages and drafts
  • Google Calendar — reading and managing events
  • Google Drive — reading and managing files
  • Google Contacts — reading contact details

Access ends the moment the account owner revokes it.

What is done with the data

Data retrieved by the tool is used only to carry out the task its owner asked for — finding a message, preparing a draft, organising a file, checking a calendar. It is processed on his own computer and by software he runs for his own work.

It is not sold. It is not published. It is not shared with third parties for their own purposes. It is not used for advertising or profiling.

Google user data

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage

Authorisation tokens are stored locally on the owner’s computer with restricted file permissions. No copy of the data is kept on any server operated by this application — there is no such server. Content retrieved from Google is held only for as long as the task at hand needs it.

Revoking access

Any account owner who has authorised this tool can withdraw that authorisation at any time at myaccount.google.com/permissions. Doing so stops all access immediately.

Contact

Questions about this policy go to julianrinta@gmail.com.
